## 📌 About The Project
**Kryptis** is a modern, highly interactive landing page dedicated to digital security awareness, built as a submission for the Technical Coordinator selection process. 

Moving away from the cliché "hacker" aesthetic, Kryptis utilizes a bespoke **"Cinematic Slate"** color grade. This design prioritizes long-term reading comfort by eliminating harsh pure blacks and whites, relying instead on a matte, neo-banking aesthetic. The project relies strictly on Vanilla JavaScript and modern CSS (zero external libraries) to deliver high-performance, hands-on interactive tools.

## ✨ Technical Features & DOM Manipulation

*   **Cinematic "Pull-Focus" Scroll:** Utilizes the JavaScript `IntersectionObserver` API and CSS `backdrop-filter` to dynamically blur inactive sections and sharpen the active viewport, mimicking a camera lens focus pull.
*   **Simulated Data Breach Terminal:** A mock command-line interface where users can input text to trigger a mechanical JavaScript scanning animation, demonstrating dynamic DOM insertion and timing events.
*   **Hardware Token Sandbox:** A visual, interactive simulation of physical security keys (e.g., YubiKey) complete with biometric pre-check mechanics.
*   **Interactive Password Validator:** Real-time DOM updates checking string length, numbers, and symbols to dynamically update a visual strength progress bar and UI text.
*   **Redacted Document Grid:** A touch-responsive radial mask effect that acts as a visual "flashlight," utilizing CSS variables updated via JavaScript coordinate tracking to declassify blurred text on hover or drag.

## 📂 Deployment & Architecture
This project is packaged into a single-file architecture for maximum portability, instant deployment, and streamlined performance.

*   **Markup:** Semantic HTML5
*   **Styling:** CSS3 (CSS Variables, Grid, Flexbox, smooth transitions)
*   **Interactivity:** ES6+ Vanilla JavaScript

## 💻 Running Locally

To run this project on your local machine:
1. Clone the repository: `git clone https://github.com/dustin-vermillion/Kryptis---CyberSecurity-Awareness.git`
2. Navigate to the directory: `cd Kryptis---CyberSecurity-Awareness`
3. Open `index.html` directly in any modern web browser. No local server or build steps are required.
